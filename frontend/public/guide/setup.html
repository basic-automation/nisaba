Setup

Install

Install Nisaba from the release for your OS (Windows installer, macOS disk image, or Linux package). Launch it — the first run opens a setup wizard that walks you through creating your first company and connecting a platform.

Companies

A company is a self-contained workspace: its own catalog, listings, platform credentials, and sync schedule. Use separate companies for separate businesses. Switching companies (the switcher in the top bar) loads that company's database and credentials; the other company's data is untouched.

Connecting a platform

  1. Open the platform setup. From the sidebar choose Settings and its Platforms tab (or run the first-run wizard), pick the platform, and flip its Enabled switch on.
  2. Gather the credentials. Each platform needs different keys — see Platform credentials for exactly what to copy from each developer portal.
  3. Save, then verify. After saving, check the credential-health panel: Nisaba validates what it can (for example, that an Amazon client secret is not past its rotation window) without touching the live network more than necessary.
  4. Import your catalog. The first sync pulls your existing listings into the local catalog as a baseline. Nothing is pushed to a platform until you approve a sync cycle — use a dry run first (see What sync does).

Where your data lives

Nisaba keeps everything on your machine:

  • Configuration — config.toml in the Nisaba data directory: %APPDATA%\nisaba\config.toml on Windows, ~/.config/nisaba/config.toml on macOS/Linux. If a config.toml exists in the folder you launch Nisaba from, that one wins (useful for portable installs and testing).
  • Database — the path in [database] path, by default ./nisaba.db next to the config. This is the file backups protect (see Backups and restore).
  • Secrets — platform tokens are stored encrypted in the database under a company secret; they are never written to logs and are redacted from the diagnostics bundle.

Test with sandbox first

eBay credentials default to the sandbox environment. Keep it that way while you learn the sync flow — flip to production only after a dry run looks right. eBay also requires your production keyset to handle the Marketplace Account Deletion requirement before your first production API call.
