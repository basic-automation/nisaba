eBay Marketplace Account Deletion exemption

Why this exists

eBay lets its users request deletion of their personal data and closure of their accounts. When that happens, eBay notifies every third-party developer application so partners can delete that user's data from their own systems too.

Because of this, eBay requires every production keyset to do one of two things:

  1. subscribe an HTTPS endpoint to the Marketplace Account Deletion notification topic, or
  2. opt out (apply for an exemption) if the application does not store any eBay user data.

Nisaba is a local desktop app: it stores your listings and inventory on your machine. It does not store eBay buyer or user personal data, so you qualify for the exemption. You must complete this before your first production API call — eBay activates the keyset only after you subscribe or opt out, and non-compliant keysets can be terminated or have API access reduced.

Per keyset, by you

Nisaba uses your own eBay keyset, not a shared one — so this is something you do once in the eBay developer portal for each production keyset. Nisaba cannot do it for you, and sandbox keysets don't need it.

Walkthrough: opting out

  1. Open the eBay developer portal at developer.ebay.com → Application keys and sign in with the account that owns the keyset.
  2. Select your production keyset. Make sure you're looking at the Production keyset, not Sandbox — the requirement (and the opt-out) applies per production keyset.
  3. Find the Marketplace Account Deletion section. In the keyset settings, look for the Marketplace Account Deletion / Closure Notifications compliance section.
  4. Choose to opt out. Select the opt-out / exemption option for not storing eBay user data, and confirm the declaration that your application does not retain eBay user personal data.
  5. Save and verify. Save the keyset settings and reload the page — the compliance status should show the keyset as opted out / compliant. If the save silently fails, check that the keyset has a proper application name set (a blank or placeholder name has been known to block compliance saves), then try again or contact eBay developer support.
  6. Connect in Nisaba. With the keyset compliant, enter your production credentials in Nisaba's eBay platform setup and authorize as normal.

If your situation changes

The exemption rests on "we don't store eBay user data". If you ever extend Nisaba's use (via plugins or exports) to retain buyer personal data — names, addresses, messages — from eBay, the exemption no longer applies: you must instead subscribe an HTTPS endpoint to the deletion notifications and honor them. When in doubt, re-read eBay's current Marketplace Account Deletion guide before your first production call — eBay updates the rules, and the portal page is authoritative.
