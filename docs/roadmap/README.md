# Roadmap notes

[`ROADMAP.md`](../../ROADMAP.md) is the checklist: one line per item, grouped by phase.
These pages hold everything behind those lines: section introductions, decisions,
findings and the detail of each item, under a heading that repeats the item's
headline, in checklist order. Finished items are folded into short summaries in the
checklist; any detail they carried stays here. When adding or updating an item, keep
its line in `ROADMAP.md` to a headline and put the detail on the matching page here.

## About ROADMAP.md

The single source of truth for work. Every item is a `[ ]`/`[x]` checkbox in phase order.
Shipped consumer-facing capability belongs in `README.md`; everything not-done, discovered
or next belongs here. There is no run log and no changelog — git history and the PRs are
the record.

Tick `[x]` only when an item genuinely shipped and was verified.
